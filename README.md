# Calculadora de fundaciones de postes de cerco

Página web para verificar fundaciones de hormigón simple (sin armadura) de postes de cerco perimetral:

- Postes intermedios, de refuerzo, esquineros y de portón.
- Viento según CIRSOC 102-2005 (procedimiento simplificado para carteles abiertos / cercos).
- Vuelco por el método de Sulzberger, profundidad mínima requerida.
- Hormigón simple: compresión local del poste empotrado, recubrimientos y tensión en el suelo.
- Puntales: arrancamiento del poste, tensión y deslizamiento de la base del puntal.
- Genera la memoria de cálculo en Word (.docx).

Abrir `Calculadora_Fundaciones_Cerco.html` en el navegador (la carpeta `lib/` debe estar junto al archivo).
Los parámetros de suelo precargados son orientativos: reemplazarlos por los del estudio geotécnico.
